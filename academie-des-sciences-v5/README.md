# Reconstruction front-end — L’Académie des Sciences

Version statique responsive inspirée de l'architecture publique du site de référence.

## Fichiers
- index.html : accueil
- 6 pages de rubriques
- styles.css : styles responsive
- app.js : menu mobile + menu déroulant

## Utilisation
Ouvrir `index.html` dans un navigateur, ou lancer un serveur local :
`python -m http.server 8000`

Le contenu long a été reformulé/remplacé afin de ne pas recopier intégralement les textes propriétaires du site tiers.
